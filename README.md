# Aliva Diagnosis Center

## Overview
Aliva Diagnosis Center is a modern, professional, and responsive static website designed for a diagnostic and pathology laboratory. The website provides information about the services offered and the importance of accurate diagnostics in healthcare.

## Project Structure
The project consists of the following files and folders:

- `index.html`: The main HTML document containing the structure and content of the website.
- `style.css`: The stylesheet that defines the layout, colors, typography, and animations for a modern look.
- `script.js`: The JavaScript file that handles form validation, animations, and interactive elements.
- `README.md`: This documentation file.

## Technology Stack
- HTML5
- CSS3
- Vanilla JavaScript

## Features
- Sticky navigation bar with smooth scrolling and mobile-friendly hamburger menu.
- Visually attractive hero section with animated floating medical cards.
- Animated statistics section showcasing experience and patient satisfaction.
- Responsive service-card grid displaying various diagnostic services.
- Interactive booking form with validation and success messages.
- Contact section with placeholder information and social media links.
- Professional footer with quick links and copyright information.

## Setup Instructions
1. Clone the repository or download the project files.
2. Open `index.html` in a web browser to view the website.
3. Ensure you have an internet connection to load external resources (e.g., Font Awesome icons).
